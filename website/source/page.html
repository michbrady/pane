The Windows file manager layout, on your Mac.

Switching from Windows? Pane gives you the File Explorer you know: a folder tree on the left, tabs, an address bar you can click and type in, a details list with sortable columns, a preview pane, and a status bar. It is a normal Mac app that works with the same files and folders as Finder.

Where your hands expect things to be

The layout and the keys follow Explorer. The window itself is a regular Mac window, with Mac menus, fonts, and your Mac’s accent color.

Navigation pane

Quick access for the folders you pin, your Mac, your cloud folders, and your servers, in one tree. Drag a file onto a folder in the tree to move it there.

Address bar

Click a part of the path to jump there, or click empty space to type a path. Press F4 or Command-L to edit it. Arrows next to each folder show its neighbors.

Tabs

Open folders in tabs with Command-T, middle-click, or Open in New Tab. Drag files onto a tab to drop them in that folder.

Details, List, and Icons

Sort by any column, choose which columns show, and see hidden files and file extensions when you want them. Folders sort first, and file2 comes before file10.

Cut, Copy, Paste, Undo

Cut and paste to move, with Undo for what you did. A name that already exists asks you to replace, skip, or keep both. A long copy shows its progress, with Cancel.

Find, preview, and properties

Search from the top bar (F3 or Command-F), preview images, PDFs, and text in a side pane, and see a file’s properties and tags.

Keys you know

F2 renames. Delete moves to the Trash. F6 moves between the tree, the list, and the address bar. Return opens an item, or renames it if you prefer Finder’s way: it is a switch in Settings.

Works beside Finder

Pane can open the folders other apps open, like Show in Finder from a download. It is off until you turn it on, and turning it off puts back what was there.

Private

No account and no tracking. Pane connects to the internet only for servers you add yourself. Privacy and terms

Servers show up as folders.

Add an SFTP, FTP, or Amazon S3 server (or any S3-compatible service, like MinIO) under Connections, and browse it like a folder: the same list, the same address bar, tabs, and keys. Copy files to and from your Mac by drag and drop, or Copy and Paste. Rename, make folders, and delete. Windows shares (SMB) mount as drives, as on any Mac.

Open a file on a server and Pane downloads it, opens it in its app, and sends your saves back. Passwords and secret keys are kept in your Mac’s Keychain, only if you ask. A server has no Trash, so Pane asks before it deletes anything there.

Servers, in short

What each kind can do in this version.

SFTP
Sign in with a password or a key from ~/.ssh. The first time, Pane shows the server’s fingerprint and asks Trust this server? A server whose key later changes is refused with a warning.
FTP
Choose FTP with TLS, the first choice, which hides your password. Plain FTP says so: it sends your password without encryption.
Amazon S3
An access key, a secret key, and a region. Add an endpoint for services like MinIO or Cloudflare R2. Buckets show as folders, and the part of a key before a slash is a folder. Files up to 5 GB.
Saved connections
Turn on Save this connection and it stays in the tree. Edit or remove it under Manage Connections. Removing one also removes its saved password.

One window, many folders.

Tabs hold their own folder, history, and selection. Pane remembers your tabs, your view, and your columns for each folder, so it opens the way you left it.

See a file before you open it.

Turn on the preview pane (Shift-Command-P) to see an image, a PDF, or a text file beside the list. Press Space for Quick Look.

Pane asks for Full Disk Access, and you can say no.

macOS keeps some folders, like Mail and parts of Library, closed to apps. Pane can show them only if you allow Full Disk Access in System Settings. Without it, Pane works on everything else and tells you which folder it could not read. Nothing is sent anywhere either way.
