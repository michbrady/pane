# Pane glossary

One name per thing. Apple's words for system actions, Windows words only
where Windows users look for them and Apple has no term.

| Term | Means | Not |
| --- | --- | --- |
| Item | A file or a folder in a list | entry, object, node |
| Folder | A directory on disk | directory, path (path is the text address) |
| File | A non-folder item | document |
| Navigation pane | The tree on the left: Quick access, This Mac, Network | sidebar, folder panel |
| Quick access | Pinned folders at the top of the Navigation pane | favorites, bookmarks, shortcuts |
| This Mac | The Navigation pane section with home, Desktop, Documents, Downloads and volumes | My Computer, Computer, This PC |
| Address bar | The bar above the list that shows breadcrumbs and takes a typed path | path bar, location bar |
| Breadcrumbs | The clickable folder names in the Address bar | trail, path |
| Search box | The field at the right of the Address bar | filter, find bar |
| Command bar | The icon row under the Address bar (New, Cut, Copy, Paste, Rename, Delete, Sort, View) | toolbar, ribbon |
| Details view | Rows with Name, Date modified, Type, Size columns | list view (List is a separate view) |
| Tab | One folder view in the title bar | window (Window is the whole Pane window) |
| Status bar | The bottom strip with item count, selection count and size | footer, info bar |
| Open | Show a folder, or open a file in its default app | launch, enter, execute |
| Go back / Go forward / Go up | Move through history, or to the parent folder | previous, next, parent |
| Move to Trash | Send items to the Mac Trash so they can come back | delete, remove, recycle |
| Delete Immediately | Remove items for good (Shift+Delete) | permanent delete, erase |
| Cut / Copy / Paste | Windows-style move and copy of items | move here |
| Rename | Change an item's name | edit name |
| Full Disk Access | The macOS permission Pane asks for to read protected folders | permission, access |
| Connection | A saved server or bucket: protocol, host, user name | account, site, bookmark, remote |
| Connect to Server | The command and sheet that opens a connection | Add Server, Map Network Drive |
| Server | An SMB, FTP, or SFTP host | host (only the field label), machine |
| Bucket | An S3 container of items | drive, volume |
